# MichoPlay release notes

## 1.0.2

### Lyrics

- Download available English captions with songs and embed them in the audio file on desktop and Android. MichoPlay removes temporary caption files after embedding them.
- Show a lyrics badge on tracks and YouTube results when lyrics are available.
- Read synced lyrics in the player, highlight the current line, and tap a line to seek to it.
- Open lyrics inline or in full mode, with artwork-based color and backdrop styling on desktop and mobile.

### Player and mobile interface

- Refine the mobile navigation bar, mini-player, and now-playing lyrics controls.
- Keep the mini-player hidden until a track is selected, while leaving the navigation visible.
- Return mobile content to the top when navigating to another page or tab.
- Improve loading skeletons, spacing, title visibility, and download status controls.

### Playlist downloads

- Choose individual playlist tracks or select all before downloading.
- Show playlist downloads as grouped progress with per-track status and playback actions.
- Save playlist tracks in a named folder under `Music/MichoPlay`; save single tracks directly under `Music/MichoPlay`.
- Use the same audio processing and available-lyrics embedding flow for playlist tracks as for single-track downloads.
